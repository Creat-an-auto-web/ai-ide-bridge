# backend-bridge

Backend bridge service for:
- Void-based desktop frontend
- the native end-to-end TDD agent pipeline
- optional OpenHands or mock execution backends

## Responsibilities
- task creation
- event streaming
- command approval
- patch delivery
- requirement analysis and exhaustive test design
- production code generation
- isolated test / implementation overlays
- bounded implementation repair loops
- protocol docs
